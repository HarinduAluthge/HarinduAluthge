## Featured work

### [SinhaSign](https://github.com/HarinduAluthge/SinhaSign) - Sign recognition with Sinhala translation

**Final Year Project | MVP ready**

A privacy-first web application that recognises webcam gestures and converts them into English and Sinhala text with speech feedback. Inference runs in the browser, so video is not sent to a server. The BiLSTM and multi-head-attention model covers 50 WLASL classes and achieved 90.93% held-out accuracy with a 0.9118 macro F1 score.

`Next.js` `React` `TypeScript` `MediaPipe` `TensorFlow.js` `Python` `Keras` `Express` `Jest` `GitHub Actions`

### Spectacle POS - Offline retail management

**Client project | Active development | Private repository**

A Windows point-of-sale and inventory system for an eyewear retailer. It covers serialized frame barcodes, stock and goods receipts, billing and split payments, customer prescriptions, lens-job tracking, receipts, reports, encrypted backups, role-based access, audit logs, and installer-based delivery.

`C#` `.NET 10` `WPF` `EF Core` `SQLite` `MVVM` `xUnit` `GitHub Actions` `WiX`

### Sinhaloka Hospital Records System - Electron healthcare desktop application

**Client-context project | Active development | Private repository**

Designing an Electron-led, offline-first hospital-records and clinic-administration application using JavaScript, React, Node.js, and SQLite. The planned interaction model covers patient registration and search, longitudinal records, prescriptions, reports, scans, eye-vision sheets, and billing, with context-isolated Electron boundaries, validated IPC, role-based access, audit trails, encrypted backups, and export workflows.

`JavaScript` `React` `Electron` `Node.js` `SQLite` `IPC` `Offline-first Design`
